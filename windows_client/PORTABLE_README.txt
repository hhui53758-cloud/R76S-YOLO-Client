垃圾分类目标检测客户端（Windows 64 位）
========================================

使用方法：
1. 请先完整解压 ZIP，不要直接在压缩软件中运行。
2. 双击 R76S-YOLO-Client.exe。
   第一次使用建议先阅读“完整用户使用说明.txt”。
3. 使用“打开图片”“打开文件夹”“打开视频”或“本机摄像头”。
   R76S 板端服务在线时，也可选择“R76S 摄像头”“R76S”推理设备或“双端对比”。
4. “批量处理文件夹”会把全部标注图片和 detection_records.csv 写入所选结果文件夹。
5. “处理并保存视频”会逐帧检测并另存为 MP4；处理时间取决于视频长度和电脑速度。
6. “停止”会停止摄像头、视频或批量任务；已写入的部分结果会保留。
7. “刷新画面”会停止当前任务，并恢复默认黑屏和清零统计。

重要：
- 不要只复制 EXE。
- 不要删除、改名或移动 _internal 文件夹。
- 模型和运行环境已包含在 _internal 中。
- 不需要安装 Python，不需要 F: 盘。
- 阈值、推理设备和窗口大小保存在当前 Windows 用户的本地配置目录中。
- 未连接 R76S 时请选“自动”或“Windows”；“自动”会在 R76S 离线时回退本机。
- “双端对比”左侧显示 Windows ONNX，右侧显示 R76S INT8 RKNN，并统计两端差异。
- 新电脑连接已部署好的 R76S 时，可运行“切换到R76S网络.bat”。
- 恢复普通有线网络时，保持 Wi-Fi 开启并运行“恢复普通网线自动获取IP.bat”；脚本会恢复 DHCP，并在需要时打开网页登录页。
- 认证期间 Wi-Fi 始终优先，不会被未认证的有线网络抢走流量；认证完成后关闭 Wi-Fi，即可实际使用有线网络。
- 不要删除两个 BAT 旁边的 network_to_r76s.ps1 和 network_to_dhcp.ps1。

模型类别：
0 可回收物
1 有害垃圾
2 厨余垃圾
3 其他垃圾
