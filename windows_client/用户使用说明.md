# 垃圾分类目标检测客户端——普通用户使用说明

本客户端支持两种完全独立的使用方式：

1. **只用 Windows 电脑推理**：不需要 R76S。
2. **连接已部署好的 R76S 推理**：使用 R76S 的 RK3576 NPU 和 USB 摄像头。

## 一、收到文件后先做什么

你收到的文件应当是：

```text
R76S-YOLO-Client-Windows-x64.zip
```

1. 右键 ZIP，选择“全部解压”。
2. 打开解压后的 `R76S-YOLO-Client` 文件夹。
3. 双击 `R76S-YOLO-Client.exe`。
4. 不要只拿走 EXE，也不要删除旁边的 `_internal` 文件夹。

客户端已经包含 Python、OpenCV、ONNX Runtime 和 `best.onnx`，普通用户不需要安装编程环境。

## 二、只用 Windows 电脑

这是最简单的方式，不需要 R76S、不需要网线，也不需要重新配置环境。

启动后把“推理设备”选为：

- `Windows`：始终使用本机 CPU/GPU 可用后端；
- `自动`：没有连接 R76S 时会自动使用 Windows。

可使用：

- 打开图片；
- 打开文件夹逐张查看；
- 批量处理整个图片文件夹；
- 打开视频；
- 处理并保存视频；
- 本机摄像头；
- 保存当前结果、导出 CSV。

结论：**如果只用 Windows，对方只要解压完整 ZIP 并双击 EXE，不需要安装任何模型环境。**

## 三、使用这台已经部署好的 R76S

这台 R76S 的系统、RKNNLite、INT8 模型和 HTTP 服务已经写在它自己的 eMMC 中，断电后不会丢失。因此，把这台实物交给别人使用时，**R76S 本身不需要重新部署环境**。

但第一次连接一台新的 Windows 电脑时，需要把该电脑的有线网卡设置成 R76S 专用地址。这叫“网络配置”，不是重新安装 AI 环境。

### 连接方式

1. 给 R76S 接通电源。
2. USB 摄像头插到 R76S；如果只检测电脑中的图片，可以不插摄像头。
3. 网线一端插 R76S 的 LAN 口，另一端插 Windows 电脑的有线网口。
4. 等待 R76S 的 SYS 红灯慢闪。
5. Windows 可以继续使用 Wi-Fi 上网，有线网口专门连接 R76S。

### Windows 有线网卡设置

R76S 已固定为：

```text
R76S：192.168.137.47
电脑有线网卡：192.168.137.1
子网掩码：255.255.255.0
默认网关：留空
DNS：留空
```

中文 Windows 可右键以管理员身份运行随包提供的：

```text
切换到R76S网络.bat
```

请让 `.bat` 与同目录中的 `network_to_r76s.ps1` 保持在一起。新版启动器本身只包含 ASCII 字符，实际设置由 PowerShell 完成，并会自动识别物理有线网卡，不依赖网卡名称必须叫“以太网”。

如果脚本提示找不到“以太网”，说明这台电脑的网卡名称不是“以太网”，需要在“网络连接”中手动给实际的有线接口设置上述 IPv4 地址。

### 在客户端中使用

- 选择 `R76S` 后，打开电脑中的图片、文件夹或视频，会把画面发送给 R76S NPU 推理。
- 点击 `R76S 摄像头`，读取插在 R76S 上的 USB 摄像头。
- 点击 `双端对比`，同一张图片会同时使用 Windows ONNX 和 R76S INT8 RKNN，左边是 Windows，右边是 R76S。
- 选择 `自动` 时，R76S 在线优先使用 R76S；R76S 离线会回退到 Windows。

## 四、用完 R76S 后恢复普通网线上网

如果要拔掉 R76S，重新把电脑网线接到学校、公司或家用路由器，请运行：

```text
恢复普通网线自动获取IP.bat
```

出现管理员确认时点击“是”。该文件需要与同目录中的 `network_to_dhcp.ps1` 保持在一起。

安全版脚本会执行以下操作：

1. 把有线网卡恢复为 DHCP（自动获取 IP、网关和 DNS）；
2. 等待普通网线接入并取得地址，先运行脚本再换线或先换线再运行都可以；
3. 在校园网、酒店等需要网页登录的网络中，直接打开真实认证页；
4. 认证完成前始终让 Wi-Fi 保持优先，避免未认证的有线网络抢走全部流量；
5. 认证完成后，如果希望真正使用有线网络，请关闭 Wi-Fi；重新打开 Wi-Fi 时会再次优先使用 Wi-Fi。

Windows 的路由选择主要看“网卡是否连接”和“优先级”，不会因为有线网络尚未完成网页登录就可靠地自动回退到 Wi-Fi。因此脚本明确采用“认证期间 Wi-Fi 优先”的安全策略。

## 五、什么时候才需要重新部署 R76S 环境

以下情况才需要重新部署：

- 给 R76S 重刷了系统或清空了 eMMC；
- 换成另一台从未配置过的 R76S；
- 删除了 `/home/pi/r76s-yolo/deploy`；
- 更换模型，并且需要更新板端 RKNN 文件或服务代码。

只是断电、换电脑、换网线或重新插摄像头，都不需要重新部署。

## 六、常见问题

### 客户端显示 R76S 离线

检查：

1. SYS 是否慢闪；
2. 网线是否插在 R76S LAN 口；
3. 电脑有线地址是否为 `192.168.137.1`；
4. 浏览器能否打开 `http://192.168.137.47:8765/health`。

### R76S 摄像头无法打开

检查 USB 摄像头是否确实插在 R76S，而不是插在 Windows 电脑；拔插一次后稍等几秒再试。

### 画面正常但没有检测框

这通常表示当前置信度阈值下模型没有识别出目标。可以适度调低置信度阈值，但过低会增加误报。

### Windows 安全提示

这是自行打包的本地程序，没有购买代码签名证书。请确认文件来自可信发送者，并核对 ZIP 的 SHA256 后再运行。
